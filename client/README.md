# TripTally

A full-stack web app that helps groups track and split expenses while traveling.

---

## Overview

TripTally is a group expense management application designed to simplify cost sharing during trips. Instead of manually calculating who owes what, users can create groups, add members, log expenses, and instantly see balances.

This project was built to solve a common real-world problem: keeping track of shared expenses in a simple and organized way.

---

## Features

- Create and manage travel groups  
- Add members to each group  
- Log shared expenses with descriptions and amounts  
- Track who paid for each expense  
- Automatically calculate balances between members
